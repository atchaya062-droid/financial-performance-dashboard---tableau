# Financial Performance Dashboard (Tableau)

## Project Overview

This project presents an interactive Financial Performance Dashboard built using Tableau.
The dashboard provides insights into sales, profit, product performance, and customer segments.

It helps businesses analyze financial trends and improve decision-making.

## Key Metrics

* Total Sales: ₹118,726,350
* Total Profit: ₹16,893,702
* Total Units Sold: 1,125,806
* Profit Margin: 14.23%

## Dashboard Features

### Profit by Product

Analyzes which products generate the highest profit.

### Sales vs Profit

Visual comparison between total sales and profit margins.

### COGS vs Sales

Tracks cost of goods sold relative to sales revenue.

### Sales by Segment

Breakdown of sales by customer segments such as:

* Government
* Small Business
* Enterprise
* Midmarket
* Channel Partners

### Sales by Country

Geographical visualization showing revenue distribution across countries.

### Monthly Profit Trend

Displays profit trends across months to identify seasonal patterns.
